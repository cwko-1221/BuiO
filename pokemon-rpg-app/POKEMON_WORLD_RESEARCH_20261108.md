## 現況稽核

- 主線在 `src/data/trainers.mjs` 的 QUEST_STAGES：博士說明星輝異變 → 草原守護者 → 海岸館主 → 峽谷與勁敵 → 神殿 → 超夢 → 自由探索。
- 目前已有捕捉、隊伍培育、進化、屬性對戰、徽章、頭目、商店、治療、圖鑑里程碑獎勵。
- 苔影森林已有道路、木橋、六個命名地標、五處遭遇區與六種遭遇表，但 NPCS 中沒有森林 NPC，QUEST_STAGES 亦沒有以森林為目標的階段。
- 森林樹木、倒木、灌木、路牌和遺跡主要是繪圖與碰撞物件。互動入口目前以路口、NPC、商店和醫院為主，尚未提供森林環境採集或通用支線任務流程。
- 部分既有對話仍稱「五大區域」，與目前六區不符。
- 普通草地依賴單一安靜材質及週期性羽化混合。近似的色彩與尺度鋪滿大面積後，林下、河岸、空地與路肩缺少區分。

## 草地與場景的改造規格（設計建議）

材質應有大、中、小三種尺度：大範圍的林蔭與濕度色帶；中等大小的苔蘚、落葉、裸土與短草群；少量清楚的小草、碎石和小花。保留乾淨通行面，讓細節聚在自然邊界與有意義的位置。

| 位置 | 地表 | 接合與低矮物件 |
|---|---|---|
| 向陽空地 | 短草、乾燥斑塊 | 小花、少量細草 |
| 樹冠下 | 深綠苔蘚、落葉腐植土 | 裸露樹根、枯枝、蕈類 |
| 河岸 | 深色濕土、小石灘 | 蘆葦、水草、浸水石頭 |
| 常走路肩 | 磨損草地、碎土 | 輕微踩踏、破碎草邊 |
| 遺跡周圍 | 土石交錯、斑駁苔蘚 | 半埋石塊、落葉、藤蔓 |

全景維持原有立體手繪方向。生成可重複使用的材質及透明小物件，靠地形遮罩和深度排序組合；不把整張漂亮插畫放大成可走地面。每套資產需以實際鏡頭和角色一起檢視。

## 地圖元素需要對應玩法（設計建議）

| 元素 | 可供玩家做的事 |
|---|---|
| 不同草地與微棲地 | 尋找不同種類、時段或條件的寶可夢 |
| 樹果樹與藥草 | 採集補給、完成委託；採過後有可見狀態 |
| 觀察點、足跡或巢穴 | 發現生態線索，解鎖圖鑑研究 |
| 巡林員、研究員、旅行訓練家 | 取得提示、接任務或挑戰對戰 |
| 路邊遺失物、拾取道具 | 讓岔路與死路有探索回報 |
| 小營地與休息點 | 恢復、補給、夥伴互動 |
| 斷木、藤蔓、石塊與高地 | 小型路線問題、可解鎖捷徑與回訪理由 |
| 古樹遺跡 | 主線事件、調查、機關或守護者挑戰 |

釣魚、露營、製作、天氣、時間與解鎖通行能力可分階段選用，不必一次加入所有世代的系統。一般道具優先使用拾取道具、失物與自然藏點；大型寶箱需要符合這個世界的美術與用途。

## 建議的全局故事結構

延續現有「星輝結晶異變」設定，建立三條互相交會的成長線：

1. 訓練家線：勁敵、各地訓練家、道館／守護者試煉和最終挑戰。訓練員應有不同隊伍與戰術特色。
2. 生態調查線：研究棲地、寶可夢行為、時段變化與異常現象。完成研究獲得調查權限、道具或新的線索。
3. 遺跡謎團線：逐區發現星輝異變的原因、相關人物的動機，以及超夢與異變的關聯。讓終章得到前面章節的鋪陳。

## 苔影森林原創章節提案：消失的林間歌聲

目標時長是設計目標，尚未經遊玩測量：首次探索約 20–30 分鐘。

開場：巡林員發現河邊的寶可夢正在離開原本的棲地，前往古樹調查的研究員也失去聯絡。玩家受託從森林入口開始尋找。

主線流程：入口接委託 → 找到兩個棲地異常線索 → 在木橋附近遇到旅行訓練家並獲得提示 → 前往遺跡找到研究員 → 完成調查／安撫或守護者挑戰 → 恢復棲地，取得指向海岸的星輝線索。

| 支線提案 | 主要行為 | 對應位置 | 回報 |
|---|---|---|---|
| 迷路的伊布 | 聽取線索、尋找、引導返回 | 蕨葉幽徑 | 親密度道具、NPC 對話變化 |
| 研究員的遺失手帳 | 探索倒木與路旁藏點、歸還 | 木橋支路 | 調查紀錄、捕捉補給 |
| 河岸急救包 | 採集指定藥草、交付 | 清溪兩岸 | 藥品與營地補給功能 |
| 森林生態筆記 | 在不同棲地觀察三種現有寶可夢 | 五處棲地 | 圖鑑研究進度、棲地提示 |
| 旅行訓練家的約定 | 可選對戰，限制或戰術逐步提高 | 道路安全空地 | 金幣、後續再戰 |
| 古樹刻痕 | 尋找三塊有提示的石碑、判讀次序 | 遺跡與觀林臺 | 新捷徑或一次性稀有道具 |

需要同時支援：任務接取／追蹤／分階段目標／完成回報、持久化世界變化、一次性領獎保護，以及任務圖示與小地圖更新。任務完成後應能看見 NPC 返回、營地開放、棲地恢復或捷徑打通。

## 實作順序建議

先做苔影森林一個完整章節：重新製作分區地表及自然接縫 → 可互動採集與拾取物 → 任務資料及存檔 → 一條主線加三條差異明確的支線 → 章節前後世界狀態 → 實機驗證探索節奏。經過實機檢驗後，把可重用系統擴展至其餘五區。
