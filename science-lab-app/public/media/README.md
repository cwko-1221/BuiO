# 觀察影片

每個探究在開始前會播一段觀察影片，讓學生先看見現象、產生疑問，然後才提出假說。

## 放檔案

檔名用探究的 id，格式 `.mp4`（H.264 + AAC，瀏覽器通用）：

    density-column.mp4    密度彩虹塔
    water-filter.mp4      清澈不等於安全
    electric-crane.mp4    電磁起重機
    light-reflection.mp4  光的反射
    heat-conduction.mp4   熱傳導比賽
    force-coaster.mp4     斜台與摩擦挑戰

放進這個資料夾就會生效，不需要重新 build——影片由伺服器直接提供，不經打包，所以
`dist/` 不會因為影片而變大。

缺少影片的探究不會壞：觀察頁會改為顯示同一組觀察提示，學生照樣可以進入下一步。

## 建議

- 時長 30–60 秒，無旁白或簡短旁白；重點是讓學生自己看出問題
- 解像度 720p 已足夠，檔案盡量控制在 10 MB 以內
- 內容只需呈現現象，不要先講原因——原因是最後「科學解釋」那一步才出現
