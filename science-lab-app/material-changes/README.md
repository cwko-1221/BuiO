# 變化研究所 · Change Lab

「可逆及不可逆變化」的獨立參賽版本。沿用空氣研究所的米白／墨藍介面、灰藍背景、白色實驗桌、清晰 HTML 標籤，以及中英文切換。

## 教學流程

沿用空氣 app 的流程：載入畫面 →「第一步：觀察」過場 → 觀察「冰 → 加熱成水 → 冷凍成冰」圖片 → 獨立提問頁 →「第二步：假說」過場 → 假說「如果材料發生變化後，我認為……」選擇題 → 六種材料自由探索。完成後先顯示「第四步：分析與反思」過場，再進入證據分析。沒有設計實驗章節、預期完成表或拍照任務。

載入畫面在 3D 器材、圖片解碼與首幀繪製完成後才結束。章節過場正常停留 1900ms，減少動態模式為 900ms；可點一下或聚焦後按 Enter／空白鍵略過。開啟設定或頁面切到背景時暫停過場計時，切換中英文保留目前章節和實驗狀態。

材料：冰、炭、朱古力、牛油、蛋白、麵包。可自由選第一種和其後各種材料的次序，但開始處理後，必須完成目前材料的觀察及記錄，才會解鎖下一種。限制由模擬層與介面共同執行，不能透過 3D 拾取或鍵盤繞過；只完成冷卻、填錯答案或換新樣本均不會解鎖。把材料器皿拖到三個處理區或返回工作台操作，沒有加熱／冷卻／冷凍／返回四個按鈕。鍵盤可選材料後按 H/C/F/B 作相同操作。記錄至少三種材料、包含炭、蛋白或麵包，才能比較可逆與不可逆證據。學生自行填寫加熱後、冷卻後和分類，不預填答案。分析只引用已完成的記錄。

每種材料的加熱後／冷卻後選項獨立定義在 data.js 的 RECORD_CHOICES，各有三項與該材料相關的描述，並提供中英文。冰只描述冰與水，蛋白只描述蛋白，麵包只描述烘烤前後的麵包，不混用其他材料的選項。記錄列表與分析頁沿用同一套材料專用文字。

加熱完成後會自動彈出「加熱後，你看到甚麼？」的 A／B／C 三選一浮窗。選擇後即顯示正確／需要修正及原因；正確確認後自動保存這一步，再繼續冷卻或冷凍。冷卻完成後自動出現第二題，最後以「最初狀態 → 加熱後 → 冷卻／冷凍後」證據鏈提出可逆性判斷。完成三題後自動儲存整份記錄並解鎖下一種，沒有手動「記錄與判斷」按鈕。冰的判斷明確連結「冰 → 水 → 冰」及固液狀態的恢復，不要求還原原來外形。關閉浮窗可拿起材料檢視，再由提示卡「繼續回答」恢復。材料仍在變化時先顯示觀察提示，避免在結果尚未出現前提問。

六種材料均可放進冷凍區。熔化材料可以重新凝固；熟蛋白和多士不會恢復成生蛋白和麵包。生蛋白也可冷凍和解凍，水分結冰時停止流動，但不會憑空增加烹調程度。記錄接受常溫冷卻或充分冷凍的證據，依實際路線寫出「冷卻後」或「冷凍後」，不把 −12°C 說成回到 20°C。

炭取代原來的蠟樣本。它使用多孔黑色炭塊、耐熱陶瓷坩堝及自動切換的供氣燃燒爐，不能用水浴燃燒。炭先在裂紋發紅、逐漸縮小，再留下少量灰白色的灰；標籤依序顯示「炭 → 炭和灰 → 灰」。加熱題、冷卻／冷凍題和分析證據都使用炭專用內容，並將它列為不可逆變化。已燒完的灰再次加熱不會生成新炭；要重新探究須換新樣本。形狀變化的反思題改用朱古力。

炭塊先焊接共用頂點，再塑形及重新計算法線，確保表面密閉，不會因每個三角面獨立位移而裂開。灰使用不規則的低矮粉末堆、細小薄碎片和散落細粒，沒有平整圓盤或大塊白色石子。charcoal-geometry.js 的網格測試檢查每條邊均連接兩個面、面朝向一致並包圍正體積。

點擊判定由 sample-picking.js 負責，只測試可見 Mesh 表面和各器皿的專用抓取範圍。液面反光線、裂紋線、隱藏物件及其他透明輔助模型不參與判定，避免前排蛋白／麵包攔截後排炭／朱古力的點擊。判定前同步相機及物件的世界矩陣；預設、縮放及轉動視角均以實際游標點擊六種材料中心驗證。

## 全桌面視覺

- 觀測讀數改為左上角的小浮動面板，3D 畫面使用整個桌面寬度。
- 六個材料選項使用內建 imagegen 生成的統一實物插圖圖集，完全內嵌。
- 炭的縮圖由 charcoal.js 使用同一組 3D 炭塊幾何繪製成透明 PNG，在載入階段產生；原圖集的蠟格不再顯示。其餘五種保留原圖集。
- 玻璃器皿是包含底部的單一連續曲面，移除舊底碟、兩層藍圈及選取光環，以折射、薄邊緣和局部反光表現玻璃。朱古力、牛油會逐漸塌下，液體攤開並變得有光澤。
- 生蛋白和熔化液體填滿器皿的錐形內壁。surface-motion.js 使用位移加速度驅動有阻尼的表面晃動，拿起、移動及停下時有漣漪，靜止後會平復；熟蛋白和完全凝固的材料不會流動。這一層不改寫科學狀態。
- 液面使用超過一千個頂點的徑向網格，含內部水波、慣性斜面及貼合液面的破碎反光。水的回彈較快，蛋白及朱古力的阻尼較大；波動按面積扣除平均高度以維持液體體積，底面保持固定。
- 拿起玻璃盤會實際提起器皿；移動目標以繪製頻率平滑跟隨游標。液面同時回應水平與垂直加速度：提起產生徑向波，橫移、轉向及停下產生慣性湧動，靜止後逐漸平復。
- 觀察浮窗放大材料名稱、溫度、狀態和提示文字，並保留左上角浮動佈局。
- 冰的熔化相變在預設 ×90 下約兩秒；熔化後器材標籤、標題和選項名稱會改為「水」，重新凝固後改為「冰」，並有放大回彈及色彩提示。中間狀態為「冰和水」。
- 重新凝固的冰是較厚的有霜面、裂紋與微小氣泡的冰塊，不是淡色平面，也不會自動變回原來的三粒冰。
- 冷凍區加入緩慢溢出的冷霧；說明明確指出白霧為凝結的小水滴，而非可見的冷空氣。減少動態模式會停用晃動和冷霧動畫。
- equipment.js 建立有水槽、控制塔及浸入探頭的水浴；有鋁製散熱鰭片及風扇的冷卻座；有保溫壁、透明前窗和開啟箱蓋的冷凍箱。麵包改用加熱區的烘烤模組。
- 白色實驗桌保留桌面厚度、裙邊、金屬桌腳及腳墊。材料加入細緻表面紋理。
- 預設縮時 ×90，比原本 ×120 慢四分之一，亦可在設定改為 ×60／×180／×360。

## 科學邊界

- simulation.js 與 Three.js、DOM 分離。每份材料有自己的溫度、相變分率／烹調程度、位置、前後證據及學生記錄。
- pointerdown 拿起時立即暫存溫度及狀態，拖回工作台後亦維持不變；重新放到處理區才繼續熱處理。這是方便觀察的教學暫存功能，沒有模擬室溫自然熱交換，介面及科學說明有註明。
- 定性縮時模型，畫面明示目前倍率。時間及讀數不是實測資料，亦非食物烹調指引。不同材料不可用本模型比較加熱速度。
- 水有 0°C 相變平台；20°C 冷卻不會結冰，必須冷凍。原始冰樣本從 −12°C 開始。
- 朱古力及牛油用示意的有效相變溫度；實際混合物有配方相關熔化範圍。
- 蛋白凝固、麵包褐變的進度不能藉冷卻倒退。
- 炭燃燒進度獨立於熔化和烹調進度：空氣充足的爐內主要碳成為氣體離開，剩少量礦物質灰，沒有把整塊炭改成等體積灰塊。720°C 爐溫及 380°C 觸發門檻僅為教學示意，並非所有炭的實測點燃溫度。模型不預測缺氧燃燒或氣體濃度。離台觀察也會暫存燃燒進度，科學說明註明真實熱炭不會因移離爐具就停止燃燒。
- 蛋白冷凍比例與受熱凝固比例獨立。示意的 −2°C 相變平台不是所有蛋白的精確凝固點；冷凍和解凍可能改變食品質感，本模型不預測這些細節。
- 重新凝固使用容器內的圓餅形狀，沒有自動還原成冰粒或分格朱古力。
- 朱古力及牛油只判斷熔化／凝固的可逆性，不宣稱恢復所有光澤、質感和微細結構。
- 「不可逆」指本次普通熱處理不能復原，非任何科技皆絕對不能。沒有把全部物理變化等同可逆，或全部化學變化等同不可逆。
- 所有器材字樣由 HTML 畫出，不是模糊的 3D 貼圖。3D 食材與器材是程式生成幾何，材質與狀態受同一模擬資料驅動。

## 建置與檢查

從 BuiO 根目錄：

```
node scripts/export-material-changes-google-sites.mjs
node --test tests/material-changes.test.mjs
node scripts/test-material-changes-google-sites.mjs
```

輸出到 exports/google-sites/material-changes。HTML 與 embed.txt 完全相同，包含 Three.js、程式、樣式及觀察圖片，不連線 CDN、登入、API 或另一個網站。

分拆原始碼亦可獨立重建：在本資料夾執行 npm install、npm run build，產生本資料夾的 dist。需要符合 Vite 8 要求的 Node 版本（建議 Node 22.12 或以上）。

Google Sites：插入 → 嵌入 → 嵌入程式碼，貼入 material-changes-embed.txt 全文。使用整頁嵌入或調整區塊寬高後預覽、發布。桌面建議嵌入高度至少 720px。實際 Google Sites 的貼入限制仍須以使用者帳戶測試；本機會測試 opaque-origin allow-scripts iframe、封鎖網路與直接開啟 HTML。

## BuiO 奇趣科學島版本

第 9 個探究站使用同一套科學模型、器材、點擊修正及材料專用題目。由 Vite 的原生多頁入口建立 `/science-lab/material-changes/`，HTML 維持平台登入保護，沒有外部網站或 iframe。平台入口只加載本機共用程式及圖片。

平台版本透過 public/js/material-changes-entry.js 接入奇趣科學島的品牌、薄荷綠／深青配色、實驗地圖、科學筆記、完成進度和設定。音效、減少動態、高對比與 3D 畫質沿用 ProgressStore；操作期間與階段確認會按學生帳號保存進度，重新整理可繼續。完成分析與反思後，地圖及筆記會標記完成。平台樣式只由 material-changes-platform.css 套用，獨立參賽版保留原有設計。

原本八個實驗繼續使用既有流程與場景。原生自由探究入口不偽裝成舊引擎的線性步驟；測試分別驗證原有八站及新的完整整合流程。

```
npm run build:science-lab
node scripts/test-science-lab.mjs
node scripts/test-material-changes-platform.mjs
node scripts/test-science-lab-live.mjs
```
