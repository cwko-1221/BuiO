# 大亂鬥技能更新 v10

所有模式使用同一套戰鬥規則，角色仍須在寵物樂園擁有才可使用。保留 v1–v9 的規則與重播分派，現有冒險存檔按建立時的版本續玩。

| 角色 | 技能與行為 |
|---|---|
| 路飛 | 橡膠手槍、橡膠機關槍各有八格新透明 sprite 動畫，含蓄力、伸長、巨大拳頭、命中及收拳。左右方向皆使用同一個手臂接點。傷害與 MP 成本沿用原來設定。 |
| 安妮亞 | 心聲標記：標記附近敵人四秒。首次成功命中該敵人增加 **8 傷害**，並使其暈眩一秒，然後消耗標記。防禦擋下攻擊時保留標記。技能本身不造成傷害。 |
| 安妮亞 | 預知結界：持續五秒，反彈 **三次近攻**；任何一次遠攻反彈會耗盡結界。反彈按該次攻擊的傷害計算；受攔截的投射物消失，不能再次命中。愛心數量及 HUD 顯示剩餘次數。燃燒等持續傷害不算直接攻擊。 |
| 多啦A夢 | 空氣炮：**35 傷害**，目標被推開約 **640px**，相當於半個 1280px 場地；到牆邊停止。 |
| 多啦A夢 | 竹蜻蜓取代任意門：飛行 **四秒**，可以移動，期間不受傷。普通攻擊發射最多 **三發射線**，每發 14 傷害，間隔 0.4 秒。顯示倒數及剩餘射線；落地恢復普通攻擊。技能費用 50 MP，冷卻十秒。 |
| 阿根廷10號 | 追蹤巧射：鎖定敵人追蹤，包含後方及不同深度的目標。會在目標跳躍、飛行或短暫無敵時等待；目標消失則重新找敵人。一般防禦仍可減傷，反彈仍可攔截。 |
| 鳴人 | 多重影分身術：召喚 **兩個真正的分身角色**，各自選敵、移動、轉向及普通攻擊。每個分身 **受到兩次傷害** 或 **十秒到期** 後化煙消失；本體倒下也會清除。再次召喚取代舊分身，不會累積。費用 38 MP，冷卻十二秒。 |

分身不增加擊殺、掉落或 MP 回復。冒險敵人可選擇攻擊附近的分身。計時使用戰鬥 tick；命中停頓不會延長飛行或分身的期限。MP 被動回復仍為每秒 2，普通命中仍只回復少量 MP。

## 驗證

- `node scripts/test-pet-brawl-utility.mjs`：傷害、暈眩、反彈次數與投射物清除、640px 擊退、四秒飛行和三發射線、後方追蹤、分身兩次受傷／十秒到期、五名角色四種模式重播、25 名 v9 角色原規則，以及兩組八格 sprite 的透明邊界。
- `node scripts/test-pet-brawl-utility-pvp.mjs`：實際 Socket.IO 雙人對戰，兩端收到分身、射線、消失煙霧及一致的伺服器狀態，雙方各扣 500 金幣一次。
- `node scripts/test-pet-brawl-utility-live.mjs`：公開大廳選擇已擁有的五名角色，iPad 尺寸截圖、左右動畫、標記與暈眩、結界次數、真實觸控飛行及射線、分身追敵和煙霧、MP 不足 UI。
- 冒險 240 場合法輸入重播、50 技能屬性測試、MP 平衡、20 章故事、對戰付款及重連、桌面／iPad／手機觸控與手勢回歸測試。
- TypeScript 檢查及正式 Vite build。

瀏覽器測試使用 Windows Chrome 的 iPad 尺寸與觸控模擬；未在實體 iPad 上驗證。所有資料測試使用獨立臨時資料庫。
