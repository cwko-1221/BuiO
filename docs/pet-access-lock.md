# 寵物樂園班級鎖定

老師登入寵物樂園後，開啟「樂園鎖定」工具。

1. 選擇一個或多個班級，可用「全選」處理本學年全部班級。
2. 「立即鎖定」提供 15／30 分鐘、1／2 小時、指定解鎖時間，或直到老師手動解鎖。再次設定立即鎖定會取代所選班級當前的鎖定。
3. 「上課時間」可選第 1–9 節；星期一至星期五每天按香港時間自動鎖定，節與節之間及放學後自動開放，不需要老師每天重新按掣。課節為：08:45–09:15、09:15–09:45、10:00–10:30、10:30–11:00、11:00–11:30、11:45–12:15、12:15–12:45、13:35–14:05、14:05–14:35。
4. 「預約時段」設定單次開始及結束時間。所有日期、時間均使用香港時間 UTC+8，即使老師裝置使用其他時區亦一樣。
5. 可加入最多 240 字的學生提示。時段結束自動解鎖；重疊或相連的預約合併計算開放時間。
6. 「立即解鎖所選班級」清除這些班級的當前鎖定、循環上課時間排程及未來預約。多班記錄會保留未選班級的設定。「取消此鎖定」只移除該筆記錄。

學生已開啟的頁面收到通知後停止操作、遊戲及音樂，並顯示獨立的鎖定畫面。頁面每兩秒檢查狀態；重新進入時須先確認開放才載入學生資料。解鎖後自動恢復樂園，冒險／練習保留暫停選單，讓學生自行繼續。推銀機保留物理盤面及已付落幣。

同學對戰的任何一方被鎖定，伺服器取消邀請／進行中的對戰。未接受的邀請不扣款，已扣入場費的對戰退回雙方各 500 金幣，並沿用原有防重複退款交易。

## 伺服器及資料

- `GET /api/pet/access`：學生自己的狀態，不接受客戶端指定班級。
- `GET /api/pet/teacher/access`：老師讀取班級、當前狀態及預約。
- `POST /api/pet/teacher/access`：老師提交 `action: lock | lesson | schedule | unlock` 及 `classes`。`lesson` 另提交 `periods: [1..9]`；時間使用含時區的 ISO 字串。
- `POST /api/pet/teacher/access/:id/cancel`：老師取消一筆設定。
- 所有學生 `/api/pet` 遊戲、商店、養成及房間入口均受統一中介層保護，鎖定時回傳 HTTP 423／`PET_APP_LOCKED`。Socket.IO 對戰亦檢查發送者、接受者及目前班級。
- 已支付推銀機落幣的普通金幣收據可完成原有結算，以免失去已獲得的獎勵；此路徑不能開始新遊戲。其他獎品申領保存在本機並等解鎖後重試。
- 班級來自本學年權威學籍；設定跟隨班級，而非登入時的舊班級快照。新學年不繼承上一學年的鎖定。
- JSON 模式儲存於 `petAccessLocks`，Postgres 模式自動建立 `PetAccessLocks`。更新使用 JSON 排隊／Postgres 交易鎖，重啟後仍保留預約。短期讀取快取最多 750ms，時間邊界仍以每次請求的伺服器時間判斷。

## 驗證

```powershell
node --test pet-app/tests/access-lock.test.js
node pet-app/node_modules/typescript/bin/tsc --noEmit -p pet-app/tsconfig.json
node scripts/test-pet-access-live.mjs
node scripts/test-pet-brawl-pvp-live.mjs
```

瀏覽器驗證使用隔離測試資料庫，涵蓋教師權限、跨班隔離、直接 API 繞過、遊戲途中鎖定、重新整理、時區、預約及重啟、自動解鎖、推銀機保留盤面、對戰退款及 iPad／手機排版。自動測試使用 Chrome 模擬觸控尺寸，沒有宣稱已在實體 iPad 或正式 Postgres 資料庫上驗證。
