## 曾發現的必要修正

1. **已解決：頭目受擊整片白化。** Swift／Nova 舊截圖中的飛船被填滿成淺色剪影。舊程式以 10 Hz 伺服器時間判斷 80 ms 的 FILL tint，持續命中可延長遮蔽。build 9 已改為 55 ms 渲染時鐘、保留材質的低強度 ADD tint，並在低動畫設定關閉閃白；已核對修正程式及新 Swift 頭目戰鬥畫面，材質清晰可見。
2. **已解決：暫停後音訊恢復的版本證據。** build 7 的加強測試曾報 `resume did not restore suspended Web Audio`。build 9 的新完整測試，在實際暫停並強制 suspend 正在運行的音訊 context 後，按恢復、等待 context 為 running 及暫停面板移除，成功通過；結論不依賴舊版報告。

除此之外，在已檢查的小遊戲畫面沒有找到必要的裁切、可讀性、缺圖或控制布局阻擋項目。不因與本次要求無關的偏好重開地圖設計。
