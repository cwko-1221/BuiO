# 全平台載入動畫與慢網絡回饋

2026-10-11。此更新涵蓋 30 個 HTML 入口，包括首頁、數學、中文、英文、功課、乘數、Phonics、報表、遊戲問答、平台遊戲、塔防、寵物、3D 科學實驗室、白板及搶答課堂。

## 使用者看到的行為

- 共用本地 `shared/loading.js` 與 `shared/loading.css`，不新增 CDN 或前端套件。載入超過 450 毫秒顯示轉圈提示；快速請求避免閃爍。
- 初次畫面、API 回應內容、Excel 元件與報表匯入、遊戲素材、寵物大亂鬥及 3D 場景準備都有載入回饋。並行工作完成後才收起提示；快取素材的遊戲亦會正確結束載入狀態。
- 超過 10 秒顯示準備需時較長；純讀取工作超過 30 秒提供重新載入。正在寫入時不提供此捷徑。
- 技術性的 Load Fail、網絡中斷及資料讀取錯誤改為中性的載入／等候動畫及重試操作，不展示原始伺服器訊息。未取得資料的設定保持不可儲存，不使用預設值假裝載入成功。
- 離線讀取等待恢復連線，保留頁面輸入。手機提示不遮擋整頁，支援鍵盤焦點、螢幕閱讀器與減少動態效果偏好。

## 重試與資料安全

- 同源 `/api/` GET／HEAD 遇到 408、425、429、500、502、503、504 或暫時網絡問題，最多額外重試三次，使用遞增間隔並尊重 Retry-After。單次等待回應標頭上限 20 秒；離線等候上限 120 秒。呼叫方取消請求會停止重試。
- 401、403、404 不在這層自動重試。授權狀態由原本登入流程處理；帶有 401／403 的回復提示提供返回登入。
- 原有課堂／對戰背景輪詢、事件串流及外部請求維持原有連線方式，避免新增大量請求。慢速外部中文字筆順資料另以工作狀態包覆。
- API 重試用完後，回復面板等待使用者按重試，避免失敗頁面不停重建提示並無限輪詢。語音服務亦只接受手動重試。
- 不自動重送 POST、PUT、PATCH、DELETE。提交、錄音及成績沿用既有交易、冪等鍵與 BuiReliable 離線佇列；技術提示不清除表單、不自動重新載入、不宣稱儲存成功。
- 必填、檔案格式、權限、金幣不足、儲存未確認及學習答題回饋保持可處理；診斷保留在開發者日誌。

## 實際限制

動畫在 HTML 與共用載入程式到達瀏覽器後才可顯示。首次連線、完全離線或 Render 免費服務喚醒期間，瀏覽器尚未收到頁面時仍需等待。此更新改善等候與重試體驗；永久服務故障、第三方服務設定或不存在的素材仍需修復根本原因，動畫本身不會令失敗操作成功。
