# 樂園金幣獎勵調整

2026-10-25。按「單項委託最高 500 金幣、魚約 50–500 金幣」調整；每日任務金幣上限預設提高至 5,000。

| 項目 | 金幣 |
| --- | ---: |
| 委託任務 | 200–500／項 |
| 常見魚 | 50／條 |
| 少見魚 | 150／條 |
| 珍稀魚 | 300／條 |
| 傳說魚 | 500／條 |
| 蘋果 | 30／顆 |
| 鮮花 | 50／束 |

| 小遊戲每日首次達標 | 最多 150／款 |
| 完成三個每日精選 | 額外最多 200 |

委託按內容分級：澆水 200；送信、香蕉、釣魚、高爾夫委託 300；橡果、森林清潔、包裹、迷宮、天空委託 400；探路、樂隊、水道和寶藏任務 500。

委託、環保巡查、遊戲和每日精選仍共用老師設定的每日上限；收購魚、蘋果和花的收入按售價直接進入錢包，不計入任務上限。新售價套用於背包內未出售的物品。既有已領獎狀態與歷史交易保留。

## 舊設定升級

金額集中於 `pet-app/lib/park-economy.mjs`，介面從同一規則顯示遊戲與精選獎勵，收購價亦由伺服器核算。

舊版 0–50 的任務上限會按版本升級一次：50 → 5,000、20 → 2,000、0 → 0；沒有舊設定時預設 5,000。新版仍可由老師設定 0–5,000。升級後重新啟動不會再次放大，老師其後明確設定的低上限或零上限會保留。

JSON 升級在寫檔失敗時回復原設定；PostgreSQL 增加 `EconomyVersion` 並更新上限約束，使舊資料庫能儲存新範圍。升級只調整上限設定，現有錢包餘額與已出售物品不變。
