# 寵物樂園：發行品質重設與驗收

2026-10-25 更新。v3 已由模組化 v4 取代；清晰地景、共用碰撞、社交合奏及持久種花已完成。Candidate 5 已通過獨立 V01–V13 覆核及完整功能檢查，本機預覽已更新並核對分發檔案。通過範圍為 Windows Chrome、本機 HTTP 及手機模擬；證據與實體裝置／正式環境限制見 [v4 紀錄](pet-park-v4.md)。

## 已驗證的問題

- 1499 × 1049 全圖放大至 5120 × 3584；在一般遊戲鏡頭中，每個來源像素被放大約兩倍，與高清角色形成明顯差異。
- 橋面和欄杆烘焙在同一張底圖，寵物一律畫在欄杆上方。橋的通行例外是膠囊形，容許站在端點外或過於靠近欄杆。
- 大量底圖花叢沒有實際碰撞；美術與可行走區分離，缺乏可信的空間規則。
- 既有測試主要確認中心通道可達，不能證明邊界、足部空間或視覺遮擋正確。
- 舊多人功能主要是看見同學和發表情，缺乏雙方共同操作的活動。

## 參考與方向

參考 [Stardew Valley 官方介紹與畫面](https://www.stardewvalley.net/press/) 的清楚地面分層、共同勞作與地標；[Animal Jam 官方寵物介紹](https://help.animaljam.com/hc/en-us/articles/360000396868-What-are-Pets-and-how-can-I-get-them) 的寵物探索及情境互動；[Webkinz 官方說明](https://webkinznewz.ganzworld.com/announcements/help/) 的邀請、接受及忙碌狀態。只採用設計原則，遊戲美術自行創作。

保留現有寵物的精緻繪本風格。使用安靜的草地、暖石小路、林下土壤、清楚的溪岸和獨立植栽；樹、住宅、花圃與橋欄都各自具有正確前後層次。路面靠材質、邊界和地標辨識，不顯示行走引導線。

## 實作邊界

1. 以 `park-layout-v4.mjs` 定義世界、步道、庭院、河道、橋面、欄杆、植物區及道具位置；渲染與伺服器讀取同一資料。
2. 以原生材質與分塊地景渲染取代放大的全圖。一般鏡頭下，地面來源紋理至少一個 texel 對一個 CSS 像素；不得將插值放大稱為新增細節。
3. `park-walkmesh.mjs` 以足部半徑及連續線段碰撞處理物理。橋面為有限多邊形，欄杆為不可穿越實體，河水只允許從橋面跨越。
4. 保留並修正現有任務、小遊戲、金幣上限、登入、同班隔離與老師鎖定。增加可接受／拒絕的附近互動與兩人共同操作遊戲；新增場景互動需有可見狀態與伺服器驗證。
5. 介面縮減常駐面板；手機預設摺疊地圖。玩家及 NPC 名字維持至少 12 CSS 像素，避免隨鏡頭縮成難讀小字。

## 不可省略的發行關卡

- [x] 美術批評者確認整體構圖、近鏡清晰度、材質比例、光線、可行走區及物件接地均合格。
- [x] 四區、橋上、橋兩端、欄杆兩側、住宅／花圃／河岸碰撞及深度遮擋有實際截圖與邊界測試。
- [x] 鍵盤、點擊、自動尋路及手機觸控均無穿越、卡住或跳越薄牆；30 人出生及走動仍可達。
- [x] 至少兩種實際玩家間互動；新合作遊戲必須由兩個登入玩家各自有效輸入才能完成。
- [x] 同意、拒絕、取消、超時、離線、重連、重複分頁、跨班及老師鎖定均有驗證。
- [x] 所有既有任務與遊戲可完成，獎勵仍冪等且受每日上限限制；不得以客戶端分數作權威。
- [x] 沒有缺圖、Phaser 缺失紋理、瀏覽器錯誤或在操作中遮擋主要遊戲區。
- [x] 瀏覽器畫面及效能證據覆蓋桌面與手機尺寸，且說明未測的實體硬件範圍。
- [x] 獨立 critic 對最終驗證產物逐項覆核；任何必須修正項未解決時，維持未驗收。
