# 寵物樂園實體商店

學生在樂園底部導覽開啟「實體商店」，以現有樂園金幣換購真實物品；「我的換領券」保留所有待領取及已核銷的券。商品及券均顯示「領取老師」，名稱由登入的上架老師帳戶自動記錄，學生可據此找老師領取。

老師在寵物樂園的「實體商店 → 商品管理」新增或編輯商品：名稱、說明／領取須知、1–1,000,000 整數金幣、可售庫存、商品圖片及上架狀態。庫存留空代表不限量；0 代表售罄。圖片支援 JPG、PNG、WebP，最大 8 MB、2500 萬像素，伺服器驗證後轉為最大 1000×1000 WebP。圖片存於資料庫，可跨部署保留，無需另外設定物件儲存。

購買一次扣除一件商品的金幣，發一張券。學生確認頁顯示金額；伺服器按實際價格核對，遇到改價、售罄、下架或餘額不足時拒絕且不扣幣。券保留購買時的名稱、價錢、圖片及上架／領取老師，日後更改商品不影響已購券。編輯保留原上架老師，另記錄最後修改者。

學生及老師介面均不顯示換領碼。老師在「換領券核銷」以學生姓名、學號或商品名稱搜尋紀錄，可查看學生姓名、班別、學號、商品及領取老師；按「核對並核銷」，核對學生身分並派發物品後按「已派發，確認核銷」。伺服器記錄核銷老師及香港時間，重試只返回既有紀錄，不能再次核銷。任何已登入老師均可核銷，方便代領處理。此版本不提供取消購買或退款。

老師商品卡的「編輯商品」下方設有「刪除商品」。確認後移除商品，停止新購買；既有換領券保留商品及領取老師快照，仍可領取、搜尋及核銷。若商品或庫存已更新，過期頁面的刪除請求會拒絕，須重新載入再確認。老師商店在固定全屏介面中獨立捲動，表單底部按鈕在桌面、iPad、手機及橫向小螢幕均可觸及。

## 資料與交易

- API 位於 `/api/pet/real-shop`，老師端位於其 `/teacher/` 子路徑；沿用樂園存取鎖定、學生及老師權限。
- PostgreSQL 初次使用自動建立 `PetRealImages`、`PetRealProducts`、`PetRealVouchers`。購買鎖定共用 `PetWallets` 及商品列，同一交易扣幣、減庫存、發券並新增 `PetCurrencyLedger`（`real_shop_purchase`）。核銷鎖定券列。
- JSON 模式使用 `petRealImages`、`petRealProducts`、`petRealVouchers`；同步原子儲存失敗會恢復錢包、帳本、庫存及券。學生刪除會清除其券，PostgreSQL 使用外鍵級聯。
- 學生只可讀取自己的券；老師可按學生或商品搜尋、分頁查看紀錄，每頁最多 200 張。核銷按伺服器記錄的券 ID 直接處理；保留舊換領碼 API 相容既有客戶端，介面不使用換領碼。
- 購買識別碼在學生 sessionStorage 保留；網絡或伺服器錯誤後仍可核對同一筆交易。重載後的「確認上次購買」不會再次扣款。商品編輯使用 revision，避免過期表單覆寫已售出的庫存。

## 驗證

`npm run check:pet-real-shop` 覆蓋 JSON／PostgreSQL 購買、防重複、權威價錢、庫存、老師名稱快照、核銷、交易中斷及學生資料清除。

`npm run check:pet-real-shop-live` 使用隔離 JSON 資料庫及真實 Chrome，操作老師上傳上架、學生購買、換領券、老師核銷、權限拒絕、成交回覆遺失後恢復，以及 iPad／手機版。截圖及驗證紀錄儲存於 `artifacts/pet-real-shop/`，不會使用本機真實學生資料。
