## 現版本的發行阻擋問題

1. **P1：地景與角色清晰度不一致。** 1499 × 1049 的地景放到 5120 × 3584 世界，桌面鏡頭 zoom 0.60 時，一個來源像素被放到約 2.05 個 CSS 像素。世界物件及角色則有較密的原生像素，形成清晰貼紙疊在柔焦底圖上的效果。把整張地圖再插值放大，不能修復來源細節不足。
2. **P1：橋的視覺表面與碰撞並非同一個物體。** 附件中寵物腳底落在木橋前側護欄外觀上。橋面、護欄、下方溪水全都烘在同一個背景深度；即使溪水中心拒絕通行，角色仍會在護欄上方被畫出來。現有 capsule 範圍不是具腳底半徑的橋面內縮多邊形。
3. **P1：背景把不可穿越的實物畫成了無碰撞裝飾。** 大量石頭、花壇、根部與溪岸在底圖內，伺服器只知道少數橢圓／樹根。玩家能站進看起來有高度的植栽或石頭，缺少可信的地理規則。
4. **P2：地面訊息過度密集。** 大量相近亮度的花、葉、碎石與房屋細節競爭；花園的背景花朵比同類可互動花床還大。低頻地面、行走面、可互動物件的層級不明。
5. **P2：重複的小樹與小屋像分散的裝飾貼紙。** 需要成組種植、接觸陰影與主次比例；四區不應只是同材質庭院加上散置物件。
6. **P2：文字實際太小。** 玩家名字為 14 世界像素，zoom 0.46 時約 6.4 CSS 像素；角色、NPC 及互動物件名稱不應跟著世界鏡頭縮到不可讀。
7. **P2：HUD 遮擋實際遊玩範圍。** 兩側卡片、永久操作提示、下方工具列與全站導覽同時存在。手機上地圖及任務卡片尤其佔位，工具列碰到互動按鈕。

## 新版本的美術方向

**溫暖的繪本寵物小鎮，清楚的可玩地面與柔和的自然邊界。** 保留寵物與優質獨立物件；地景改為原生清晰材質、可控地形與分層物件。

- 地面降低對比、花朵尺寸和高頻紋理，讓角色及可以操作的物件先被看見。花團放在花壇及道路外緣，林地用葉層、蕨與陰影區分。
- 石路以溫暖奶油色與低矮邊石表現；廣場放寬，連接路收窄，彎角必須足以讓玩家讀出方向。道路上不加入路線指引線。
- 每區有一個主輪廓：家園小屋／廣場噴泉與遊戲攤／花園苗圃與水道／林間樹洞與探索路。主要物件周圍留可聚集的空地。
- 水面、橋面、岸邊、牆和植栽使用同一份幾何資料作繪圖與通行；可以走的裝飾地被不可畫得像腰高障礙。
- 橋使用獨立的底層橋面、後欄與前景護欄。角色腳底只在橋面多邊形內活動，前欄遮住前緣，禁止碰撞範圍延伸到欄外。
- 獨立高物件按照腳底／底座深度排序。樹冠可自然遮擋，角色進入遮擋區時可柔和淡化，但不使用浮起的高光圈取代場景地理。

### 尺度及材質預算

- 發行鏡頭下，地面至少有 **1 個原生來源 texel / CSS 像素**。這是下限；不能以放大 PNG 充當原生來源。
- 例如 1536 原生像素的地面區塊覆蓋 2048 世界單位，在 zoom 0.62 時有約 1.21 來源像素 / CSS 像素。512–1024 材質以約 1 世界單位 / 原生像素使用也有足夠密度。
- 目前 house 的 900 原生像素對應 645 世界單位，zoom 0.62 下約 2.25 來源像素 / CSS 像素；地面和獨立物件不能出現現版本那麼明顯的清晰度落差。
- 材質可重用，但不可顯出棋盤縫、週期亮斑或整齊的重複花團。道路、庭院、溪岸的輪廓應由地理資料決定，不由不受控的生成畫面決定。
- 單張大地圖再重畫或再銳化仍然是錯誤架構。四塊不連貫的風景圖也不合格；模組化地景必須共享道路及邊界。
