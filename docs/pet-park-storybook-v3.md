# 樂園地圖重製：溪畔童話花園

> 歷史版本：本機預覽已改用 [模組化 v4](pet-park-v4.md)。以下整張背景及其座標方案已被取代，不能用作目前地圖的通行或驗收依據。

2026-10-21。此次目標是恢復場景的美術完整性，解決過寬的道路、反覆平鋪的草地、零散物件及過多地面標示。

## 構圖與美術規格

- 四個有主題的場景：家園的花園小屋、廣場的噴泉市集、東北的花海水庭、西北的林間樹洞。
- 蜿蜒溪流建立清楚地理關係；北側木橋、南側石橋連接兩岸，成為自然可辨識的路口。
- 步道採柔和弧線及自然收放，進入廣場後展開成石庭。尋路以主路中央 180 世界單位、林徑中央 152 單位為優先，庭院容許自然斜行。
- 使用整張原創繪製地景，統一石材尺度、植栽、柔光及接觸陰影。草地採細緻而安靜的灰綠筆觸，避免大片重複的高飽和草坪。
- 花叢、低蕨、溪岸和林下陰影形成景深；獨立樹木、建築及互動物件保留前後遮擋。
- 畫面不顯示行走路線、地面目的地圈、道路中心線、編號驛站牌或任務地面光圈。

## 製作方式

先建立道路、庭院、溪流及橋樑草案，輸出構圖參考。內建 ImageGen 依構圖及原廣場美術參考重新繪製全圖，再完成一次保留構圖的細節修整。生成結果會偏離草案，因此 `park-landscape.mjs` 改用最終圖片座標逐段校正，讓伺服器通行範圍對齊畫中的橋面，避免硬套生成前的座標。

實際選用原圖為 1499 × 1049，保留原生尺寸並包裝為 quality 96 WebP；沒有把插值放大宣稱為高解析度。單張紋理小於 2048，約 1 MB。執行時只載入連貫地景及使用中的獨立物件，舊的草坪、四區底圖與程式畫線不再載入。鏡頭採較寬視野並預留上方空間，減少房屋屋頂被切掉的情況。

原始圖、構圖、完整提示詞及版本紀錄保存在 `artifacts/park-art/storybook-v3/`。

- `terrain-source.png`：第一輪完整繪製；`terrain-detail-source.png`：實際選用的細節修整版。
- `prompt.txt`、`detail-prompt.txt`：兩次內建 ImageGen 的完整提示詞。
- `layout.png`：原始構圖參考；`surveyed-layout.png`：對齊成圖後的尋路資料示意，僅供製作檢查，不在遊戲顯示。
- `package-pet-park-storybook.mjs`：無重畫、無平鋪的 WebP 包裝與內容雜湊檔名。

## 驗證

37 個互動入口及 30 個出生點均可達；兩座橋可通行，溪水拒絕直接跨越。既有 12 個任務及兩款小遊戲保留。單元檢查涵蓋移動、任務、遊戲與 PostgreSQL 金幣交易；Chrome 實機瀏覽器檢查四區、兩橋、無引導線、任務追蹤、手機觸控、暫停與老師鎖定。手機為瀏覽器模擬，未宣稱實體裝置測試。

畫面與報告：`artifacts/pet-playtest/storybook-v3/`。本機預覽使用 `http://localhost:3000/pet`。

最終結果：TypeScript、11 項樂園／遊戲／資料庫檢查、寵物核心檢查及 4 項發佈產物檢查通過。瀏覽器完整四區巡覽與手機冒煙測試通過，無缺圖或瀏覽器錯誤。已同步本機 build 並重啟預覽；入口 JS 和地圖 WebP 的實際 HTTP 內容均與驗證產物的 SHA-256 一致。NPC 停步點亦已留出空間，避免對話前角色互相遮擋。
