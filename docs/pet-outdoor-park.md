# 寵物小鎮：第一階段

**目前版本為四區環路、12 個委託、六種操作／解謎活動及兩款獨立小遊戲。** 最新規格、素材與驗證見 [冒險版本文件](pet-park-adventure-v2.md)。下文保留第一階段紀錄。

四區已完成統一的 2.5D 美術，包含完整互動物件、人物、環境、地圖與房間出口。最新素材、提示詞、四區截圖及新版 30 人測試紀錄見 [完整美術文件](pet-park-world-art.md)。

學生在自己的房間點「出去樂園」後，寵物會走到出口，進入戶外的家園小徑。也可從「戶外樂園」分頁進入。戶外有家園小徑、星願廣場、四季花園及微光森林，四區透過步道連接。地圖範圍為 5120 × 3584 世界座標，鏡頭跟隨寵物，可用點地移動、方向鍵／WASD 及觸控搖桿操作。

## 本期內容

- 四位 NPC：郵差兔、熊園長、鹿園丁、松鼠探險員；各有統一畫風的角色素材、專屬對話及頭像。
- 共 32 個可接近的地點／互動物件，包括 NPC、住宅入口、委託板、長椅、噴泉、花圃、池塘、果樹、路牌、樂器、橡果及步道垃圾。
- 六款委託：送信、澆花、收集橡果、閱讀路標、試奏樂器、清理森林。每天依香港日期確定三款，所有任務都能單人完成。
- 小地圖、大地圖、NPC 導引、任務追蹤、同學名單和三種快捷表情。點選任務的導引會實際步行至下一站。
- 同學的主寵和已穿戴飾物在戶外沿用既有 PetAvatar 素材；長椅上的寵物位置、表情及物件互動效果也會同步。
- 每日三個委託的獎勵為 8–15 枚，全部完成額外 5 枚；全校每人每日上限預設 50，老師可設為 0–50。已發放的金幣不會因調低上限而扣回。

## 權限和同步

`/pet-park` Socket.IO namespace 使用現有簽署登入 session。房間由本學年的權威學籍決定，同班學生進入同一房間；未分班帳戶各自使用私人房間。客戶端不能指定另一班房間、其他學生、位置結果或獎勵金額。

伺服器以固定頻率處理移動意圖及路徑，客戶端平滑顯示位置。重要建築、樹木和池塘的碰撞與尋路使用共用規則。世界狀態目前由單一 Node.js 實例持有；多實例部署需先加入共享房間協調及 Socket.IO adapter。

所有可得任務進度的互動須先靠近物件，取得伺服器的短期互動票據並完成等待。接委託及交付也會驗證 NPC 距離。伺服器確認每日委託、已接任務、各步驟及每日金幣上限；三個任務的完成獎勵和每日額外獎勵各自只發一次。

老師的樂園鎖定沿用現有規則，會中止移動／待處理互動並移除該班在線寵物。解鎖後可恢復已儲存進度。切到背景會停止移動及互動。重複分頁以最後一次進入者取得控制權；離線及回家時保留最近位置。

JSON 模式保存於 `petParkProgress`／`petParkSettings`。PostgreSQL 模式自動建立 `PetParkProgress`／`PetParkSettings`，與既有 `PetWallets`、`PetCurrencyLedger` 使用同一交易。失敗時不會只發金幣而沒有寫入任務進度。刪除學生亦會清理其任務紀錄。

## 驗證方式

```text
npm run build:pet
npm run check:pet-park
npm run check:pet-park-live
```

資料測試使用隔離 JSON fixture 與 PGlite PostgreSQL 引擎，涵蓋尋路、防重領、香港午夜、每日上限、儲存失敗回復及刪除關聯資料。瀏覽器測試使用隔離資料及 Windows Chrome，以學生和老師身份走過出口、多人同步、任務、重連、教師設定、鎖定、觸控和回家流程；測試截圖及報告位於 `artifacts/pet-playtest/outdoor-park/`。測試不會修改本機學生資料或連接正式資料庫。

2026-10-19 的完整瀏覽器驗證通過，沒有頁面 JavaScript 錯誤。30 名同班學生在 1024 × 768 的 Chrome 視窗成功同步及顯示，取樣約 60 FPS；另驗證 390 × 844 手機直向操作。未分班帳戶的私人房間隔離及持續權限檢查亦通過。原有房間操作在 320 至 1440 像素寬的九種尺寸通過回歸測試。這些結果是桌面 Chrome 的模擬尺寸，尚未在實體 iPad 或正式 PostgreSQL 服務驗證。

本期尚未加入後四區、小火車、邀請合作小遊戲或每週共同活動。它們可沿目前世界資料、物件與任務介面擴充。

## 中央廣場美術樣板

中央廣場已加入內建 ImageGen 製作的分層 2.5D 美術，包含九款素材、獨立噴泉與橡樹、園長、委託板、長椅及樂器。建築、樹根與噴泉的碰撞沿用伺服器共用規則。原始素材、提示詞、打包命令和樣板限制見 [美術紀錄](pet-park-art-sample.md)。其餘地區仍待美術重製。

這次美術版本通過雙人 Chrome 的真實遊戲測試，桌面取樣約 60 FPS，並檢查 1024 × 768 平板及 390 × 844 手機視窗、素材載入、園長對話、物件互動、繞路及前後遮擋。上述 30 人測試屬美術更新前的功能驗證。新截圖及報告位於 `artifacts/pet-playtest/wish-plaza-v1/`。樣板尚未部署。
