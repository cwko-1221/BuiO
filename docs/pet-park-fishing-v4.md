# 池畔慢釣 v4：試餌、不確定性與收放角力

2026-10-30。按「不應太容易釣到魚、試餌也可能游走、不要感嘆號輔助、提竿後要有角力與刺激感」調整。

## 等待與試餌

魚兒不再在拋竿後很快就被吸引，也不會隨等待時間自動擴大注意範圍、把遠處的魚拉過來。只有游近浮標的魚才有機會注意魚餌，並按每條魚的好奇程度作隨機判斷；牠可能一直不理會，學生可觀察魚群再重新拋竿。

魚可能靠近後不碰魚餌就離開，也可能輕碰一下或數下後游走。這些是試餌，不會算作釣獲，也不會自動收回魚線；同一竿仍可繼續等待另一條魚。離開的魚會有一段不再理會魚餌的時間。真正吞餌時才有較深的下沉和水聲，提竿窗口約為 1.25–1.6 秒。

已移除池面的感嘆號、真正咬鉤時的按鈕變色，以及直接宣告咬鉤的狀態文字。等待與真正咬鉤時維持相同的「提竿」按鈕和觀察提示，由學生看浮標、魚兒動作及聽水聲判斷。

## 魚兒角力

- 魚會在隨機的衝刺和喘息階段之間切換。衝刺會把收線進度拉回，浮標和魚身會左右猛拉；竿身按張力彎曲，魚線變緊。
- 衝刺時應停手，讓魚線鬆一點；魚慢下來時，才有節奏地連按收線。按住按鈕不會自動收線。
- 魚線過緊而不放鬆會拉斷；長時間不收線則可能因鬆線讓魚逃走。不同魚的力量不同，較強的魚更難控制；隨角力及有效收線，魚的體力會下降。
- 下方只保留張力和收線進度兩項主要資訊，角力時收起水域快捷按鈕。音樂會切換到較快的角力節奏，配合衝刺、魚放鬆、收線及斷線的原創音效。

每局改為 120 秒，達標仍為兩條魚，讓較長的等待和實際角力都有空間。背包、魚價、售魚入帳及任務獎勵規則沿用原有設定。
