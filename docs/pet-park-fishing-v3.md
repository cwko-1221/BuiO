# 池畔慢釣 v3：滑動拋竿與活魚池

2026-10-29。釣魚改為「滑動拋竿 → 魚群游近 → 觀察試餌 → 浮標沉下時提竿 → 連續點按收魚」。

參考 [Play Nintendo 官方釣魚教學](https://play.nintendo.com/news-tips/tips-tricks/fishing-new-horizons-tips-and-tricks/)中觀察魚影、把浮標投向魚前方，以及以明顯水聲辨認真正咬鉤的節奏。連按收魚是本樂園按使用者要求新增的操作。

## 操作和表現

- 在池面滑動，放手的位置決定落點；落點限制在實際水面，無須鎖定原本三個固定釣點。短點可先瞄準，再用拋竿按鈕操作；三個水域按鈕保留作快捷選擇。
- 九條可見的魚會巡游、轉向和游離。靠近浮標的魚有機會注意魚餌，再真正游到浮標旁。魚的種類、位置和行為由伺服器保存及更新。
- 每條魚試餌一至三次，浮標輕輕上下移動；真正咬鉤時浮標明顯沉下並抖動，配合擴散水波、水花、「！」及獨立水聲。提竿窗口為 2.1 秒。
- 提竿後以約每秒三次的節奏點按收魚。每次有效點按才增加進度，停按約三秒魚便會逃走；長按不會自動收魚。收線進度和逃走警示放在下方，池面保留作觀察。
- 保留原有精緻池塘和二十種魚的圖片，以透明度、移動、擺尾和水面波紋呈現水下魚群。釣魚音樂加入柔和和弦；十個原創短音效涵蓋拋竿、落水、魚兒發現浮標、試餌、咬鉤、提竿、收線、拉扯、釣獲及逃走。
- iPad 的長按選取保護保留；空白鍵及主要按鈕仍可操作。滑動取消、旋轉、暫停、老師鎖定和離開都會清理輸入。

## 存檔與驗證

獲得魚的種類、尺寸、分數及背包紀錄由伺服器計算。連按有頻率限制，重送相同計數不會增加進度，跳大計數也不能一次收魚。原有魚獲全屏展示、欣賞期間暫停計時、收竿保存、圖鑑、商人出售和錢包入帳沿用現有交易流程。
