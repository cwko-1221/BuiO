# 寵物樂園：清楚路線與冒險玩法

2026-10-21：地圖美術與行走顯示已由 [溪畔童話花園 v3](pet-park-storybook-v3.md) 取代。下方地圖／導引段落保留作舊版紀錄；12 個委託與兩款小遊戲繼續使用。

2026-10-20 更新。地圖維持 5120 × 3584，採用四區環形主路、支路及四個編號驛站。取代舊版背景各自畫好的裝飾小路；路面、尋路、地圖與碰撞使用同一套配置。

## 地圖與導引

- 240 單位寬石路連接家園、廣場、花園及森林，128 單位支路通往各活動。攤位、住宅與花圃的支路會繞過實體物件。
- 共 37 個地點／互動物件，新增水道機關、香蕉攤、天空遊戲機及兩座廣場小屋。
- 點地、任務導引與大地圖都優先沿步道尋路，仍可自由進入草地。移動時顯示實際路徑、目的地與預計步行秒數，可取消導引。
- 手帳可選定追蹤一個委託，地面只標記該委託的目標；選擇按學生及香港日期保存在分頁中。

## 十二個委託

所有委託每天都可接受，其中三項為每日精選；完成全部精選另加 5 金幣。全部活動可單人完成，錯誤可重試，不消耗金幣。

| 委託 | 操作與內容 |
| --- | --- |
| 把好消息送出去 | 探訪鹿園丁及松鼠，交付兩封信，再向郵差報告 |
| 花園今天很口渴 | 三片花圃的澆水時機挑戰，在綠色範圍按下按鈕 |
| 栗栗的橡果收藏 | 讀取位置線索，在六處落葉中尋找橡果 |
| 樂園探路小隊 | 沿環路探索三個地區，調查方向路牌 |
| 廣場的小小樂隊 | 重奏三、四、五個音符的記憶旋律 |
| 讓森林亮起來 | 從垃圾袋找出紙袋、鋁罐、果核，分別分類 |
| 失蹤包裹追蹤記 | 按次序讀便條、搜索長椅落葉、到樹洞找包裹 |
| 森林回音密語 | 調查蘑菇，再到樹洞完成旋律記憶 |
| 救救花園的水道 | 調查水源，旋轉九格水管，連接入口與出口 |
| 三枚符號的寶藏 | 收集三條數字線索，依符號次序解開樹洞密碼 |
| 為野餐接住香蕉 | 到攤位進入遊戲，接住至少八顆，再向郵差交付 |
| 天空巡遊實習生 | 用自己的寵物參加天空巡遊，擊破至少六個泡泡 |

探索筆記保存親自調查的線索。一般調查使用短期互動票據；操作活動則由伺服器發題、驗證答案、完成時間、位置與委託次序。

## 獨立小遊戲

**香蕉接接樂**：45 秒，左右鍵／A、D 或滑鼠／觸控拖曳。接香蕉、金香蕉、五連接額外加分；避開扣心的橡果。後半段掉落更快並有橫向飄移。

**寵物天空巡遊**：60 秒，方向鍵／WASD 或滑鼠／觸控拖曳。沿用自己的寵物和穿戴，自動發射星星，躲避泡泡與星雨。三波敵人後迎戰巨雲，空白鍵或觸控按鈕可使用三次護盾。

兩款均有說明、遊戲、生命／時間／分數、暫停、結算、紀錄及重玩。每款每日首次達標有 8 金幣；遊戲、所有委託及精選額外獎勵共用老師設定的 0–50 每日上限。仍可繼續練習並更新當日最高分。

伺服器以固定 30Hz 步進運行遊戲，10Hz 發送狀態。客戶端只傳操作，不提交分數或獎勵金額。結算驗證登入、地點、session、完成狀態、香港日期及教師開放狀態，並在同一交易寫入錢包、ledger、最高分及任務進度。暫停／背景會停止遊戲；斷線或教師鎖定會終止未完成的局數，已結算資料保留。

## 素材與檔案

- 世界與路網：`pet-app/lib/park-world.mjs`；活動與遊戲規則：`park-activities.mjs`、`park-games.mjs`。

- 原始 PNG 與完整提示詞：[`原始素材`](../artifacts/park-art/adventure-v2/)／[`prompts.json`](../artifacts/park-art/adventure-v2/prompts.json)。

## 驗證

```text
node scripts/build-pet-park-adventure-art.mjs
npm run build:pet
npm run check:pet-park
npm run check:pet-park-live
npm run check:pet-park-sync
```

TypeScript、Vite production build、JSON／PGlite 測試及完整 Chrome 實玩均通過。瀏覽器測試使用隔離臨時資料，不修改學生資料或連接正式資料庫，包含全部活動、兩款遊戲、重複結算、上限、重新整理、30 人、觸控及遊戲中的教師鎖定。截圖與機器可讀報告：[`adventure-v2`](../artifacts/pet-playtest/adventure-v2/)。手機和平板採桌面 Chrome 模擬尺寸，未聲稱已驗證實體裝置或正式 PostgreSQL 服務。

世界及遊戲目前由單一 Node.js 實例持有；多實例部署需共享房間協調及 Socket.IO adapter。
