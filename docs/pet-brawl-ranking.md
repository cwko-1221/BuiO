# 大亂鬥排名對戰

大亂鬥保留「自由對戰」，新增「排名對戰」及「全校排行榜」。兩種對戰各收取每人 500 金幣，接受邀請後才會同時扣款；拒絕、取消及邀請逾時都不收費。自由對戰不影響排名。

## 級別及晉級

| 目前級別 | 在此級別勝出多少場可晉級 | 下一級別 | 每日金幣 |
| --- | ---: | --- | ---: |
| 沒有級別 | 5 | 銅 | 0 |
| 銅 | 10 | 銀 | 100 |
| 銀 | 20 | 金 | 300 |
| 金 | 40 | 鑽 | 500 |
| 鑽 | 最高級別 | — | 1,000 |

每一級的勝場分開累積。升級後該級勝場歸零，總勝場仍保留；輸掉及平局不會清除晉級進度，也不會降級。由沒有級別到鑽共需要 75 場排名勝利。所有學生由沒有級別開始，原有自由對戰不會轉成排名勝場。

只有相同級別可邀請及接受排名對戰。伺服器在發出邀請時檢查一次，再在接受邀請的扣款交易內檢查一次；若期間級別改變，邀請失效且雙方不扣入場費。學生必須持有出戰寵物，並符合原有上線、金幣及老師鎖定限制。

## 結果及排行榜

對戰模擬及勝負由伺服器決定。正式開始後的投降或單方斷線逾時會計勝負；平局計入遊玩場次，但不增加勝場。載入失敗、開場前取消、伺服器重啟及老師鎖定等退款場次不計排名。

全校排行榜列出目前學年仍在校的學生，顯示姓名、班級、級別、總排名勝場、勝率及排名遊玩場次，並標示自己。老師和已畢業學生不列入。排序依次為級別、該級別勝場、總勝場、勝率、場次，最後按姓名及學號固定次序。勝率是總排名勝場除以排名遊玩場次，顯示至小數一位；未遊玩顯示「—」。

介面提供晉級進度、每日金幣狀態、不同級別的對手提示、明確的排名邀請及晉級結算。主要操作按鈕至少 56px 高；窄螢幕的排行榜可在表格內橫向捲動。

## 每日自動獎勵

獎勵按香港日期計算。伺服器啟動時及每分鐘為符合資格的學生自動入帳，離線學生亦會收到；登入和讀取排名時也會補查。伺服器停機期間漏發的日期會在恢復後一次補發。

升級當日會立即補足新級別的每日金額。例如已收到銅級 100 金幣後升銀，只再收到 200 金幣，當日合共 300。每天以獎勵游標及金幣交易唯一識別碼防止重複入帳，重新整理、重複請求及重複結算不會再次派發。

## 儲存及維護

- JSON 模式使用 `petBrawlRanks`；Postgres 模式自動建立 `PetBrawlRanks`，每名學生一筆排名。
- 金幣交易使用 `PetCurrencyLedger` 的 `brawl_rank_daily` 類別。Postgres 的排名結算、升級、派幣及對戰結果在同一交易完成；錢包與排名以固定學號順序鎖定。
- JSON 儲存失敗會還原排名、錢包、交易紀錄及對戰狀態。刪除學生時同時清除該學生的排名。
- `GET /api/pet/brawl/ranking` 只供已登入且未被鎖定的學生使用，回傳個人排名、級別規則及全校排行榜。
- 目前沒有賽季重置或降級機制。

## 驗證

```sh
npm run check:pet-brawl-ranking
npm run check:pet-brawl-ranking-live
```

規則及伺服器測試覆蓋所有晉級門檻、輸掉不清零、香港午夜、離線補發、升級差額、重複結算、儲存失敗還原、同級邀請及接受、退款、全校排序、重新載入持久性及帳戶刪除。瀏覽器使用隔離 JSON 資料和真實 Socket.IO，檢查排名對戰、拒絕邀請、升級結算、老師鎖定退款、中英文、iPad 尺寸及手機版。

既有自由對戰協議、自由對戰瀏覽器流程、寵物模組及推銀機發佈檔檢查亦通過。觸控裝置使用瀏覽器尺寸及觸控模擬；本次沒有在實體 iPad 或正式 Postgres 資料庫執行測試。
