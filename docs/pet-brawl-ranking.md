# 大亂鬥排名對戰

大亂鬥提供「自由對戰」、「排名對戰」及「全校排行榜」。自由對戰每人 500 金幣；排名對戰按雙方級差收取每人 100–500 金幣。接受邀請後才會同時扣款；拒絕、取消及邀請逾時都不收費。自由對戰不影響排名。

## 級別及晉級

| 目前級別 | 該級晉級積分 | 下一級別 | 每日金幣 |
| --- | ---: | --- | ---: |
| 沒有級別 | 25 | 銅 | 0 |
| 銅 | 50 | 銀 | 100 |
| 銀 | 100 | 金 | 300 |
| 金 | 200 | 鑽 | 500 |
| 鑽 | 最高級別 | — | 1,000 |

每一級的積分分開累積。達到門檻便升級，積分由 0 重新開始，不帶入超出的分數；總勝場及場次仍保留。敗方扣分，但積分最低為 0，不會降級。平局雙方不加減分。鑽級仍可累積積分，供全校排行榜排序。

新學生從沒有級別、0 分開始。原有排名的級別、總勝場、勝率及場次保留，該級既有勝場按每場 5 分一次轉成積分，不追扣以前敗場；舊每日獎勵游標亦保留。原有自由對戰不會轉成排名成績。

## 跨級對戰、積分及入場費

所有級別均可互相邀請排名對戰。沒有級別也計作一級，因此與鑽級相差四級。

| 級差 | 低級勝高級 | 高級勝低級 | 每人入場費 |
| --- | ---: | ---: | ---: |
| 0 | +5 | +5 | 500 |
| 1 | +7 | +4 | 400 |
| 2 | +9 | +3 | 300 |
| 3 | +11 | +2 | 200 |
| 4 | +13 | +1 | 100 |

敗方扣除與勝方獲得相同的分數，並遵守最低 0 分。例如鑽級對銀級：銀級勝出加 9 分、鑽級扣 9 分；鑽級勝出加 3 分、銀級扣 3 分。雙方各付 300 金幣。低級勝高級每差一級多取 2 分；高級勝低級每差一級少取 1 分。

邀請及對手按鈕會顯示雙方級別、自己的勝負加減分和實際入場費。伺服器發出邀請時記下雙方級別，接受時在扣款交易內重新檢查；若級別改變，邀請失效且雙方不扣入場費。入場費及分數由伺服器重新計算，客戶端不能自行設定。正式開始後採用該場確認的級差結算。學生必須持有出戰寵物，並符合原有上線、金幣及老師鎖定限制。

## 結果及排行榜

對戰模擬及勝負由伺服器決定。正式開始後的投降或單方斷線逾時會計勝負；平局計入遊玩場次，但不增加勝場或積分。載入失敗、開場前取消、伺服器重啟及老師鎖定等退款場次不計排名，並退回各人實際支付的入場費。

全校排行榜預設只顯示首 10 名，超過 10 名時提供「展開全部」及「收起至首 10 名」按鈕。個人排名摘要仍會顯示，方便不在首 10 名的學生查看自己的成績。

排行榜涵蓋目前學年仍在校的學生，顯示姓名、班級、級別、該級積分、總排名勝場、勝率及排名遊玩場次，並標示自己。老師和已畢業學生不列入。排序依次為級別、該級積分、總勝場、勝率、場次，最後按姓名及學號固定次序。勝率是總排名勝場除以排名遊玩場次，顯示至小數一位；未遊玩顯示「—」。

介面提供晉級進度、每日金幣狀態、不同級別的對手提示、明確的排名邀請及晉級結算。主要操作按鈕至少 56px 高；窄螢幕的排行榜可在表格內橫向捲動。

## 每日自動獎勵

獎勵按香港日期計算。伺服器啟動時及每分鐘為符合資格的學生自動入帳，離線學生亦會收到；登入和讀取排名時也會補查。伺服器停機期間漏發的日期會在恢復後一次補發。

升級當日會立即補足新級別的每日金額。例如已收到銅級 100 金幣後升銀，只再收到 200 金幣，當日合共 300。每天以獎勵游標及金幣交易唯一識別碼防止重複入帳，重新整理、重複請求及重複結算不會再次派發。

## 儲存及維護

- JSON 模式使用 `petBrawlRanks`；Postgres 模式自動建立 `PetBrawlRanks`，每名學生一筆排名。
- 金幣交易使用 `PetCurrencyLedger` 的 `brawl_rank_daily` 類別。Postgres 的排名結算、升級、派幣及對戰結果在同一交易完成；錢包與排名以固定學號順序鎖定。
- JSON 儲存失敗會還原排名、錢包、交易紀錄及對戰狀態。刪除學生時同時清除該學生的排名。
- `GET /api/pet/brawl/ranking` 只供已登入且未被鎖定的學生使用，回傳個人排名、級別規則及全校排行榜。
- 目前沒有賽季重置或降級機制。

## 驗證

```sh
npm run check:pet-brawl-ranking
npm run check:pet-brawl-ranking-live
```

規則及伺服器測試覆蓋所有 25 種級別配對、雙方勝出時的分數與費用、所有晉級門檻、扣分最低 0、不降級、舊資料一次轉換、香港午夜、離線補發、升級差額、重複結算、儲存失敗還原、邀請期間級別變更、實付退款、全校排序、重新載入持久性及帳戶刪除。瀏覽器使用隔離 JSON 資料和真實 Socket.IO，檢查同級及跨級排名對戰、拒絕邀請、升級結算、400 金幣老師鎖定退款、首 10 名及展開／收起、中英文、iPad 尺寸及手機版。

既有自由對戰協議、自由對戰瀏覽器流程、寵物模組及推銀機發佈檔檢查亦通過。觸控裝置使用瀏覽器尺寸及觸控模擬；本次沒有在實體 iPad 或正式 Postgres 資料庫執行測試。
