# 專注花園「再來一次」

老師的倒數頁在暫停／繼續按鈕旁提供「再來一次」，使用本次參加學生、班級或組別標籤、完整倒數時間、音量上限、起始獎勵及每次超標扣減，建立新一輪挑戰。超標次數歸零、剩餘獎勵回復起始值。操作及確認按鈕至少 56px 高，適用 iPad 和手機。

進行中或暫停時，先提示本次未發放獎勵將被放棄，老師可選重新開始或保留本次挑戰。完成或已結束時可直接再開一輪；先前已完成的獎勵保留，亦不會因重試再次發放。

麥克風須成功啟用才重新開始。拒絕權限時保留原挑戰並暫停；回應遺失時找回新一輪並暫停，避免重複開局。建立新一輪期間切換老師工具，也會暫停新挑戰。

伺服器透過原本老師專用更新端點接受 `action: restart` 和防重複識別碼。每輪最多建立一個後續挑戰，參加學生直接沿用原輪的名單。JSON 會一次儲存舊輪結束及新輪建立，失敗時還原；Postgres 在同一交易及老師鎖內處理。

驗證指令：`npm run check:pet-quiet-room`、`npm run check:pet-quiet-room-live`。測試涵蓋設定及名單保留、重新計時與獎勵、防重複、儲存失敗還原、未完成不派幣、已完成不重複派幣、權限拒絕、回應遺失、工具切換及 iPad／手機版。瀏覽器採用隔離 JSON 資料及 Web Audio；沒有在實體 iPad 或正式 Postgres 資料庫測試。
