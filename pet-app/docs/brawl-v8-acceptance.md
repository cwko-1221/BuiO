# 大亂鬥 v8 驗收

2026-10-03。25 隻角色及 50 招保持開放，所有出戰模式仍核對寵物持有權。

- 燃燒在火焰多段命中期間實際扣血，最後命中後持續 3–4 秒。灼燒不回補 MP、不累積連擊、不造成額外硬直，會自然消失。
- 冰柱冰封 1.2 秒，累積冰傷冰封 1 秒；首領縮短至 0.4 秒，解凍後有 3 秒抗性。冰封期間仍可被追擊，受擊無敵不會被冰封延長。
- MP 自然回復由 6 降至每秒 2；50 招成本提高 25% 向上取整，為 25–60 MP。普通攻擊最多回補 2 MP，技能不從傷害回補 MP。
- 敵人／首領 HP 約增加 15%，基礎傷害提高，保留可反應的預警、難度限制及免費重試。
- 技能鍵有屬性色框、MP 成本、十分之一秒冷卻倒數與進度條；不足時顯示差額。冰封、麻痺、空中與動作中也顯示不能施放。不可用技能不送出鍵盤／觸控輸入；一直按住原本不可用的鍵，不會在恢復可用時自動施放。
- iPad 技能鍵 148×92 px，防禦／跳躍 88×88 px，攻擊 104×104 px。手機橫向不裁切；局部暫停時倒數停止。

## 驗證

- TypeScript 與 Vite 正式建置通過，正式發佈檔案的入口、付費推幣機、WASM Brotli 和資源預算檢查通過。
- `check:pet-brawl-balance`：MP 數值、灼燒不中斷／不產生硬直、冰封控制與追擊、首領抗性，以及 25 個封存 v7 角色的完整一致重播。
- `check:pet-brawl`：27 組完整合法闖關通關及伺服器重播，持有權、重試、存檔與冪等獎勵。
- `check:pet-brawl-elemental`、`check:pet-brawl-roster`：50 招真實效果、成本、元素狀態、物理與圖素範圍、舊版相容、25 角色持有權與收費。
- `check:pet-brawl-cat`、`check:pet-brawl-pvp`：貓的換位及預先連爪、兩人獨立輸入、邀請接受／拒絕、付款、退款、斷線及重啟。
- `check:pet-brawl-balance-live`：正常選角及觸控施招，燃燒持續傷害、冰封與解凍、冷卻與 MP 不足、暫停和按住不可用鍵的行為；1024×768 與 667×375 畫面。
- `check:pet-brawl-elemental-live`：50 招實際渲染；六種大型效果於 Chrome 觸控模擬約 60 FPS，池化圖素上限 72，沒有錯誤或漏載。
- `check:pet-brawl-roster-live`：25 隻角色及 50 招正常載入，悟空／鳴人真人同步；拒絕免費，接受雙方各付 500。
- `check:pet-brawl-live`：教學、AI、iPad 多點觸控、直向暫停、IndexedDB 續關、網路結算重試只領一次獎勵，以及返回房間的清理。
- `check:pet-brawl-input-live`：桌面、iPad 尺寸和手機橫向的防縮放／長按選字、多點觸控、持續攻擊與離開後恢復。

證據位於 `artifacts/pet-playtest/brawl-v8/`，`balance-browser/` 有就緒、冷卻／MP 不足、燃燒、冰封與手機畫面。所有學生與錢包測試使用隔離資料。Chrome 觸控模擬不代表實體 iPad Safari 效能；PostgreSQL 本次未實測。

`legacy/v7/` 的八個檔案已與調整前的 Git 原檔逐一比對，僅改相對匯入路徑；v1–v7 規則保留，以免更改既有闖關的重播和結算結果。
