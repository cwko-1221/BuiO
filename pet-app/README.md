# BuiO 寵物樂園

`/pet` 是與平台登入及學年班別整合的獨立寵物養成模組。學生進入斜角臥室孵蛋、餵食、換裝、佈置及切換主寵，也可進入俯視角冒險；老師進入同一路徑可切換發放金幣及安靜房間。

## 功能範圍

- 目前公開 3 個完成版原創品種、每種四階，共 12 個形態；其餘設計保留在素材庫而不對學生顯示。
- 寵物蛋只會孵出目前三隻完成版，未擁有品種優先；重複品種以金幣補償。
- 400／1,100／2,100 XP 進化門檻及香港時間每日 100 XP 上限。
- 12 款食物、16 款寵物綁定技能、80 款穿戴及 100 件家具。
- 10 間 12×10 格線臥室、共用的全黑星空 iPad 延伸背景，以及 10 張三波戰鬥加首領地圖。
- 同班私人參觀控制、匿名每日表情，以及不含聊天、交易或排行榜的安全社交。
- 老師個人或整班發幣預覽、1–10,000 整數驗證、不可變帳本及防重複提交。
- 安靜房間：選擇全班，或班內中文／英文／數學單一組別；設定 10 秒至 120 分鐘倒數、音量上限及每人獎勵／每次懲罰。音量為裝置麥克風相對指數 0–100，並非校準分貝，可先測試課室再調整。聲音只在本機分析，不錄音或上傳。
- 老師安靜房間以「寵物專注花園」呈現課堂專注挑戰：日光庭園背景、清醒寵物、鼠尾草綠／奶油白介面、圓環倒數及即時音量面板。插畫來源與提示詞記錄於 `art-source/quiet-focus-garden-v1.md`。
- 花園寵物沿用既有 sprite 正面 idle 循環、播放速度及各畫格停留時間；三隻夥伴錯開小動作，倒數暫停時仍維持 idle。「減少動畫」設定會改為靜止畫格。
- 設定頁與倒數頁分開顯示：設定頁可選擇參加對象、時間、音量上限、獎勵和懲罰，並即場測試麥克風；開始後顯示獨立倒數花園及暫停控制。完成或結束後可返回設定；重新整理會恢復至暫停的倒數頁。
- 音量到達上限即時計一次超標，短促聲音也會觸發；回復至門檻以下 3 點並保持安靜 1 秒後才再次觸發。已移除音量指數原有的 12 dB 偵測增益，同樣聲音在未封頂區間約降低 20 點；同一上限需約四倍輸入振幅才會觸發，100 對應接近麥克風數碼最大輸入。預設上限保持 30，滑桿向右調高可容許更多聲音。懲罰只減少本次待發金幣，最低 0。完成後以伺服器交易一次發給開始時的參加名單，學生沿用老師獎勵通知。
- 每次偵測到超標，即時顯示暫計扣分並播放響亮的三聲警告蜂鳴，伺服器回覆後校正數字；持續超標不重播，暫停時停止音效。警告音與短暫回音期間保留音量顯示，暫不重新啟動超標偵測。
- 暫停停止倒數及扣分；離開頁面、切換老師工具或麥克風中斷時暫停，重新整理後須手動繼續。伺服器使用 6 秒偵測租約，斷線超過租約後保留進度並暫停。結束挑戰不發獎勵。麥克風需 HTTPS 或 localhost 及瀏覽器授權。
- 推銀仔是付費經濟遊戲：每次成功落幣由伺服器原子扣除 1 枚金幣；普通金幣每枚入槽獎勵 1 枚（紅寶石仍為 50、兌換券不變）。有效 payout event 只可按該局及 event idempotency 各入帳一次，已提交的舊 +10 回覆不重新定價。學生 session、重複提交、餘額不足及每局 payout 上限均在 API 層驗證。重試使用共用退避（5–60 秒並遵守 Retry-After）；舊回覆不能放大額度，4xx 永久拒絕保留暫存待核對，401/403 提示重新登入，連續失敗只提示一次。開發用 unlimited-money 端點只在明確設定 `NODE_ENV=development` 且只接受 POST，正式 client artifact 不包含該端點。
- JSON 與 PostgreSQL 雙資料模式；刪除學生時連帶清除其寵物資料。
- 推銀仔特殊獎品：新機台開局 1 件，此後每 100 次成功付費落幣補 1 件（原本每 20 次）；輪流出現紅寶石、寵物券、飾物券及家具券，盤面最多 4 件。舊機台保留既有獎品與券，從採用新規則時再玩 100 次才補貨；重設、重複請求和舊落幣紀錄不會額外生成獎品。

## 執行與驗收

```text
npm run build:pet
npm run check:pet
npm run check:pet-live
npm run check:pet-quiet-room
npm run check:pet-quiet-room-live
```

`check:pet` 驗證內容數量、素材、蛋與保底、XP、技能綁定、房間、地圖獎勵和防重複提交。`check:pet-live` 使用本機 Chrome 在桌面、iPad 橫向及手機尺寸實際操作學生與老師流程，截圖存於 `artifacts/pet-playtest/`。

安靜房間測試使用隔離的 JSON 資料庫；單元測試涵蓋倒數、暫停、音量閘、防重複扣減及結算。瀏覽器測試以 Web Audio 音源驗證音量、組別／全班結算、權限拒絕、進度恢復及手機版，截圖存於 `artifacts/pet-playtest/quiet-room/`。

## 素材管線

`node scripts/generate-pet-assets.mjs` 可重建專案內 WebP 素材。最終輸出包括 80 個透明角色種子圖、80 套四方向 × 12 動作圖集、10 間房、10 張地圖及碰撞描述、180 件獨立收集品、12 個敵人家族、10 個首領和 16 套技能特效。素材清單與完整提示詞保存在 `public/assets/art/manifest.json` 及 `public/assets/art/PROMPTS.md`。

聲音由 `src/audio.ts` 的本地 WebAudio 音符事件即時產生，包含 12 個循環音樂主題、20 組聲線變化及介面、養成、戰鬥與佈置音效；沒有載入第三方音樂或品牌素材。

## 結構

- `lib/catalog.js`：伺服器權威內容、價格與規則。
- `repositories/pet.repo.js`：交易性養成／經濟資料層。
- `routes/pet.js`：角色保護的公開 API。
- `src/game/`：Phaser 房間與冒險 Scene，只處理畫面、相機與輸入。
- `src/main.ts`：商店、背包、圖鑑、參觀、設定與老師端 DOM 介面。
