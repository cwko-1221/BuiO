# 月灣海岸小鎮

從寵物樂園的學生頁面開啟「海岸小鎮」。六區透過步道、兩座石橋和山坡階梯相連。可使用方向鍵、WASD、手機方向掣或點選步道，也可以從全島地圖選擇目的地。

遊玩畫面與全島地圖共用固定低視角。遊玩地表採用九張獨立繪製的分區材質。橋欄、植被、建築與其他前景具獨立遮擋深度。十三款原創動物有各自的 3D 模型與步行動畫。其他角色由金毛幼犬嚮導同行。
