# 大亂鬥技能特效 v11

這次以已認可的路飛橡膠拳和機關槍圖集作美術基準，為其餘 48 招建立各自的八幀透明圖集。路飛原有兩張圖集和內容雜湊保持不變，合計 25 位角色、50 招、400 個動畫幀。

原圖使用 Codex 內建 `image_gen.imagegen` 生成。每一招在一次生成中完成完整八幀，沒有使用 CLI、API key、程式重畫或單幀複製。完整實際提示、來源圖片和參考圖片列於 [jobs.json](jobs.json)。PNG 是原始生成檔；遊戲載入的是無損 WebP 圖集。

每招包含準備、形成、蓄力、釋放、爆發、跟進、消散和恢復。飛行中的遠攻使用完整飛行幀；命中、召喚煙霧和收招使用後段幀。持續火焰、光束、場地、護盾和竹蜻蜓各有相應播放方式，沒有把所有技能當成一次性貼圖。

`node scripts/build-pet-brawl-v11-fx.mjs` 從原圖提取完整連通姿態，保留越過近似格線的完整效果，統一縮放並固定中心、地面或發射端錨點。每張輸出 2048 × 512，每幀 512 × 256，留透明邊界避免滲色。輸出名稱含內容雜湊；保留舊檔以支援已載入的版本。

`node scripts/test-pet-brawl-skill-art.mjs` 驗證 50 張獨立圖集的透明度、尺寸、幀差異和邊界，並產生五張完整八幀檢查圖。`scripts/test-pet-brawl-skill-fx-live.mjs` 檢查遊戲內兩個朝向、實際幀播放、按角色載入、效能和退出清理。報告及截图存於 `artifacts/pet-playtest/skills-v11/`。

鳴人分身在 v11 規則下各只有 1 HP，生成後最多存在 180 個模擬 tick（3 秒），遭到一次有效攻擊即以煙霧消失。分身使用正常角色外觀，頭上沒有分身文字、倒數或血條。技能按鈕仍顯示一般 MP 和冷卻狀態。v10 完整規則存於 `lib/brawl/legacy/v10/`，以保留舊存檔和伺服器重播。
